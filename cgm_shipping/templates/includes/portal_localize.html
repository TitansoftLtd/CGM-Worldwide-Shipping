{# Reusable timezone-aware datetime macros for the CGM customer portal. Usage in any portal template: {% from "templates/includes/portal_localize.html" import local_datetime, local_date %} {{ local_datetime(c.creation) }} {{ local_date(shipment.custom_eta) }} What you get: 19-05-2026 07:22:11 am The fallback text inside is what the server thinks (system-tz formatted). `public/js/portal_localize_time.js` runs on DOMContentLoaded and rewrites the inner text to the browser-local equivalent.
